# 🎋 竹知了 · Bamboo Cicada

一转就「哇鸣—哇鸣」的中国传统竹蝉玩具,3D 仿真网页游戏版。

竹知了是一根竹签穿过竹筒手柄,顶端装着两片薄竹片;双手搓动竹签,
竹片高速旋转切割空气,发出酷似夏日蝉鸣的「哇鸣」声——转得越快,
声音越响、音调越高;转速慢下来,声音也跟着变闷变低,直到停下。

## 快速开始

```bash
cd zhuzhiliao
node server.js
```

浏览器会自动打开 `http://127.0.0.1:8080`(或手动访问)。
**必须通过服务器访问**(摄像头手势需要 localhost/HTTPS 安全上下文,
直接双击 index.html 无法使用全部功能)。

## 玩法

| 操作 | 效果 |
|---|---|
| 在竹知了上按住来回滑动(鼠标/手指) | 搓动竹签,持续加速 |
| 快速一甩 | 给竹片一个冲量 |
| 空白处拖动 / 双指缩放 / 滚轮 | 旋转、拉近视角观察 |
| 📷 摄像头手势 | 双手合掌放在镜头前,来回搓动掌心 |
| 📳 摇一摇 | 晃动手机加速(iOS 需点按钮授权) |
| 空格 / ← / ↑(按住) | 键盘搓动 |
| M / C | 静音 / 开关摄像头 |

## 挑战玩法

- **⏱️ 连续鸣叫**:保持竹知了不停鸣叫,冲击 10s / 20s / 35s 目标,
  短暂停顿有 0.45s 宽限,超过即中断重来。
- **💨 极速冲刺**:突破 600 / 1100 / 1700 RPM 大关。
- 鸣叫期间按转速持续得分;**最高分、最高转速、最长连续鸣叫纪录自动保存在本机**
  (localStorage),刷新页面不丢失。

## 仿真设计

- **物理**:搓动力矩 + 甩动冲量驱动角速度;空气阻力按
  `线性项(层流)+ 二次项(湍流)`建模,外加竹签与竹筒的静摩擦;
  最大持续搓动平衡转速约 2300 RPM,松手后约 10 秒自然衰减到无声。
- **声音**:全部由 WebAudio 实时合成,无任何音频文件——
  双锯齿波 + 低八度方波作载波,带通滤波器塑形;
  振幅以**叶片通过频率(2×转/秒)**调制,产生低速「哇——哇——」
  到高速密集蝉鸣颤音的自然变化;载波基频随转速从约 240 Hz 连续
  爬升到 2800 Hz(音调变高);响度用平滑包络,转速降下声音自然消失;
  高速叠加带通噪声模拟"切风"嘶声。
- **3D**:Three.js 构建竹签、竹筒手柄、双叶竹片(带竹纤维程序化纹理),
  高速旋转时叠加**残影拖尾 + 旋转模糊圆盘**,转速越快残影越强;
  竹签在竹筒内高速抖动,叶片轻微进动,模拟真实玩具的动态。
- **手势**:MediaPipe HandLandmarker(本地模型)识别双手掌心相对
  搓动速度,映射为搓动力矩;摄像头画面以画中画显示骨架跟踪。

## 验证

项目自带三层自动化验证,全部在本机真实执行过:

```bash
npm test                          # ① Node 断言:物理/声音映射/挑战逻辑(35 项)
node scripts/cdp-selftest.mjs     # ② 真实浏览器栈(有头 Edge + CDP)跑页面内
                                  #    自检 38 项,含 WebAudio 离线渲染
                                  #    (高速有声 RMS>0 / 停转静音)与 WebGL 冒烟
node scripts/cdp-interact.mjs     # ③ CDP 合成真实鼠标/键盘事件验证
                                  #    搓动加速→甩动→空气阻力衰减→
                                  #    键盘加速→音频联动→摄像头降级
node scripts/cdp-analyze.mjs      # ④ 页面内像素采样:HUD/画布/运动模糊
node scripts/cdp-overlay.mjs      # ⑤ 开始界面真实点击流程
```

浏览器内自检(服务器运行中):访问 `http://127.0.0.1:8080/?selftest=1`,
结果写入页面与标题。`?demo=1` 为自动演示模式(自动周期性搓动),
`?nosplash=1` 跳过开始界面。

## 手机访问

1. 手机与电脑连同一 WiFi;
2. `node server.js` 启动后会打印局域网地址(如 `http://192.168.x.x:8080`);
3. 手机浏览器打开该地址。**注意**:局域网地址上浏览器会禁用摄像头
   (需要 HTTPS),此时搓动、摇一摇、挑战等全部功能可用;想用手势
   操控可在本机 `http://127.0.0.1:8080` 体验。

## 迁移到其他目录(如 F 盘)

整个文件夹是自包含的(依赖已内置在 `vendor/`),
用管理员权限把 `zhuzhiliao` 文件夹复制到目标位置即可,再执行
`node server.js` 启动。

## 目录结构

```
zhuzhiliao/
├─ index.html          页面与 HUD
├─ css/style.css       响应式样式
├─ js/
│  ├─ physics.js       旋转物理(空气阻力)
│  ├─ audio-map.js     声音参数映射(纯函数)
│  ├─ audio-engine.js  WebAudio 合成引擎
│  ├─ logic.js         计分与挑战逻辑
│  ├─ textures.js      程序化竹材质纹理
│  ├─ scene3d.js       Three.js 场景/残影/粒子
│  ├─ input.js         鼠标/触摸/键盘/摇一摇
│  ├─ hands.js         MediaPipe 手势操控
│  ├─ game.js          主循环与 HUD
│  ├─ selftest.js      页面内自检
│  └─ main.js          入口
├─ vendor/             three.js / MediaPipe 模型(本地,离线可用)
├─ tests/core.test.mjs Node 测试
└─ server.js           零依赖静态服务器
```
