# 端到端自验证报告

> 本文档记录 Aegis 的验证方法与结果。验证可随时复现：`aegis demo`（或 `python -m aegis.demo`）。

## 验证方法

验证以「样例企业知识库」为基础：虚构「星云科技」公司的 5 份文档
（TXT 员工手册 / DOCX 差旅制度（含表格）/ PDF 信息安全制度 / XLSX 报价单 / PPTX 战略发布会），
覆盖全部 5 种支持格式。验证环境为**完全离线**（本地嵌入 + 确定性 LLM 后端），
保证结果可复现；接入真实 LLM 后流程不变。

验证脚本每个阶段带**硬断言**（`check()`），任一断言失败即以非零状态退出。

## 验证项清单

| # | 阶段 | 验证内容 | 断言要点 |
|---|---|---|---|
| 0 | 样例生成 | 5 种格式文档生成 | 文件数 = 5 |
| 1 | 文档入库 | 解析→切块→向量化→Chroma | 5 文档全部入库、分片数合理 |
| 2 | 语义检索 | 向量 + BM25 混合检索 | 命中《差旅报销制度.docx》且含关键数字 600 |
| 3 | MCP 工具与安全 | 计算器 / 白名单 / 注入 | 12*8+6=102；越权调用被拒；注入表达式被拒 |
| 4 | 多智能体问答 | Planner→Retriever→Auditor→Answerer | 答案含 600 + 引用来源；工具计算进答案 |
| 5 | 审核防幻觉 | 知识库无依据的问题 | 如实说明「没有依据」而非编造 |
| 6 | HITL 审批 | 敏感工具挂起/批准/拒绝 | 挂起→审批单；拒绝→不执行；批准→执行 |
| 7 | 幂等入库 | SHA-256 去重 | 重复入库不产生重复文档 |
